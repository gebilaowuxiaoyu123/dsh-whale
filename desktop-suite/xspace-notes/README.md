# XNoteWidget（XSpace 同系列的小工具工程）

> desktop-suite 里的一个插件包。这里放的是 **XNoteWidget**（.NET 9 WPF）工程 + 一些早期调查资料，
> 以及从 `C:\xspace_notes`、`C:\xspace_home.html`、`C:\xspacenews,html` 收拢过来的文件。

- **许可**：MIT（见 `LICENSE`）—— 自家工程，源码入库。
- **不入库**：`bin/`、`obj/`、`dist/*.exe`（构建产物，换设备重新 `dotnet build` 即可）。
- **构建**：`cd XNoteWidget; dotnet build -c Debug`
- 它**不参与开机自启**，属于随包带的工程/资料。
